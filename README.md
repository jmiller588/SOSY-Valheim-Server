# SOSY 1.0 - Valheim Dedicated Server

Welcome to SOSY 1.0! This repository contains the modpack profile and installer for our private Valheim dedicated server.

## Getting Started

### Requirements

- Valheim installed through Steam
- [r2modman](https://thunderstore.io/package/ebkr/r2modman/)
- Windows 10 or Windows 11

### Installation

1. Visit the [Latest Release](https://github.com/jmiller588/SOSY-Valheim-Server-Copy/releases/latest).
2. Download `SOSY-1.0-Installer.zip`.
3. Extract the ZIP file.
4. Run `Install-SOSY.ps1`.
5. Follow the instructions to import the SOSY 1.0 profile into r2modman.
6. Launch Valheim using **Start modded** in r2modman.

The first launch may take a few minutes while the mods download.

## Included Mods

| Mod | Purpose |
|---|---|
| BepInExPack | Mod framework |
| Jotunn | Modding library |
| Equipment and Quick Slots | Additional equipment and quick slots |
| Quick Stack | Inventory management |
| PlantEverything | Expanded planting options |

## Server Connection

**Server:** `valheim.millerhomedomain.com`  
**Port:** `2456`

Connect using Valheim's **Join IP** option.

Server access requires the server password, which will be provided separately.

## Important Notes

- Always launch through r2modman using **Start modded**.
- Keep your mod versions synchronized with the server.
- Don't update individual mods without coordinating with the server administrator.
- This repository does not contain the Valheim game files or world save.

Have fun!
