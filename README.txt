SOSY 1.0 - VALHEIM MODDED SERVER
================================

Welcome to SOSY 1.0!

REQUIREMENTS
------------
- Valheim installed through Steam
- r2modman installed
- An internet connection

INSTALLATION
------------

1. Extract the entire SOSY-Installer folder.
2. Run Install-SOSY.ps1.
3. Follow the instructions displayed by the installer.
4. In r2modman, select Valheim.
5. Import the local profile using SOSY-1.0.r2z.
6. Select the imported SOSY 1.0 profile.
7. Click Start modded.

The first launch may take a few minutes while the mods download.

CONNECT TO THE SERVER
--------------------

Server: valheim.millerhomedomain.com
Port:   2456

Connection address:
valheim.millerhomedomain.com:2456

1. Launch Valheim using Start modded in r2modman.
2. Select Join Game.
3. Choose Join IP.
4. Enter the connection address above.
5. Enter the server password when prompted.

IMPORTANT
---------
Always launch Valheim using Start modded in r2modman.
Launching directly through Steam will not load the mods.

Do not update individual mods unless coordinated with the
server administrator. The client and server need compatible
mod versions.

MODS INCLUDED
-------------
- BepInExPack
- Jotunn
- Equipment and Quick Slots
- Quick Stack - Store - Sort - Trash - Restock
- PlantEverything

Have fun!
